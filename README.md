## About Health Core Light

Health Core Light is a web application with expressive, elegant syntax. Health Core Light is accessible, powerful, and provides tools required for large, robust
applications in the healthcare business.

via [juanm.cortez@gmail.com](mailto:juanm.cortez@gmail.com). All
security vulnerabilities will be promptly addressed.
